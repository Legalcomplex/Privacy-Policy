# Privacy Policy

The canonical Privacy Policy for **Legalcomplex**, **Legalpioneer** and **Sabaio**.

- **Read it:** [PRIVACY-POLICY.md](PRIVACY-POLICY.md)
- **Rendered on the site:** [legalcomplex.com/privacy-policy](https://legalcomplex.com/privacy-policy)
- **Current version:** 2 July 2026, replacing the August 2020 policy

## Why the policy lives in git

The commit history of this repository *is* the revision history of the policy. Both
the policy itself and the page on legalcomplex.com point here, so anyone can see
what changed, when, and what the text said on any past date. A privacy policy that
can be edited silently is worth less than one that cannot.

`PRIVACY-POLICY.md` is the canonical text. The page on the website is a rendering
of it. If the two ever disagree, this file governs and the page is a bug: please
[open an issue](../../issues).
